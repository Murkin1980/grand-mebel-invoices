# ИП "ГРАНД МЕБЕЛЬ" — Счета на оплату v2.0

Веб-приложение для создания, хранения и экспорта счетов на оплату.

## Что нового в v2.0
- Современный дизайн с боковым меню
- **Редактирование счётов** (новая функция)
- **Автоматическая вставка печати и подписи** в генерируемые Excel-файлы
- Итоговая сумма в реальном времени при создании счёта
- Поиск по счетам, контрагентам и товарам
- Улучшенный экспорт Excel (правильный файл без сохранения на диск)
- Статистика на главной странице
- Защита от удаления контрагента с активными счетами
- Базовое автоматическое тестирование (`test_app.py`)

## Установка и запуск

### 1. Установите зависимости:
```
pip install -r requirements.txt
```

### 2. Запустите:
```
python app.py
```

### 3. Откройте: http://localhost:5000

## Структура
```
invoice_app/
├── app.py              # Основной код
├── test_app.py         # Автоматизированные тесты
├── requirements.txt    # Зависимости (Flask, openpyxl, Pillow и др.)
├── instance/           # БД SQLite и сканы печати/подписи (stamp.png, signature.png)
├── templates/          # HTML шаблоны
│   ├── base.html       # Базовый шаблон (навигация, стили)
│   ├── index.html      # Список счетов
│   ├── invoice_form.html # Форма создания/редактирования счёта
│   ├── invoice_view.html # Просмотр счёта
│   ├── contractors.html  # Контрагенты
│   ├── products.html     # Товары и услуги
│   └── esf_settings.html # Настройки (загрузка печати/подписи и ЭСФ)
├── esf_client/         # Клиент ИС ЭСФ
│   ├── esf_client.py   # SOAP клиент
│   └── esf_models.py   # Модели ЭСФ
└── Aa123456/           # Папка с ЭЦП
    └── GOST512_*.p12   # Файл сертификата
```
